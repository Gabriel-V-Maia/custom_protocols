# Implementação com tunnel UDP usando playit

O plano gratuito de playit apenas deixa nós usarmos um tunnel UDP, e não TCP...

E eu devido a limitações da minha provedora, não posso expor meu file server pra internet, então decidi tentar fazer uma alternativa usando o protocolo UDP e criando checksums robustos com Blake

Eu chamo ele de RUSP
